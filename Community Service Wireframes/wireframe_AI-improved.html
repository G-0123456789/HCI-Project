Universal Components (All Screens)

📶 Universal Status Bar

Consistent navigation bar rendered in base.html via Django template inheritance. Shows app name, connectivity icon, and battery. Included on every screen via {% block statusbar %}.

🎤 Voice-to-Text

Web Speech API widget injected via static/js/voice.js. Fills form textarea with transcribed text. Supports isiZulu, Sesotho, English. Critical for low-literacy users like Mrs. Van Nuil.

📴 Offline Mode Indicator

⚠ Offline — queued

Service Worker caches app shell. Pending reports stored in IndexedDB. Synced via Django REST API on reconnect. Addresses CityMenderSA evaluation requirement.

🔔 Notification Loop

Django Signals trigger Celery tasks on status change. Sends WhatsApp messages via Twilio API or Firebase Cloud Messaging push. Reference ID included in all notifications. Template: notifications/status_update.txt.
